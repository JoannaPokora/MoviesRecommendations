# Movies Recommendation

The objective of this project is to develop a recommendation system for movie ratings using the following algorithms: Non-negative Matrix Factorization (NMF), two versions of Singular Value Decomposition (SVD1 and SVD2) and Stochastic Gradient Descent (SGD). Our approach further extends the basic models by incorporating modifications of NMF and SVD2, as well as two alternative loss functions for SGD.

All models are evaluated using the root-mean-square error (RMSE).
